# Biome and weather atmosphere

Enable **Sky & atmosphere → Biome & weather atmosphere** to use Hytale's fog, sky and cloud colours. It is Off by default.

The setting follows the game's blended environment values, so it also applies to caves, portals and custom environments. It keeps Aurora's surface lighting, exposure and colour-grading controls separate.

- **Atmospheric fog** turns the above-water fog effect on or off.
- **Fog density** scales the environment's fog.
- Cloud colours and opacity follow the active weather.
- Underwater depth fog remains active.
- **Night sky blue** applies to Aurora's atmosphere when this setting is Off.

Changes apply immediately and can be saved in a custom profile.

When enabled, this takes priority over [Atmosphere model](clouds-and-sky.md). Turn it off to compare Classic and Enhanced sky/haze.
